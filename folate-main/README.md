# Folate

Folate is a lightweight web UI for experimenting with conversational prompts and previewing generated content.

## Features

- Prompt-driven chat UI and playground components
- Mobile and website templates in `constants/`
- Supabase helper utilities in `lib/`

## Requirements

- Node.js 18+ (or LTS)
- npm or yarn

## Install

```bash
npm install
```

## Run (development)

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Environment

Copy `.env.example` to `.env` and update any necessary keys before running locally.

## Contributing

1. Fork the repository
2. Create a branch (`git checkout -b feature/your-feature`)

## Repo structure (selected)

- `components/` — React components
- `constants/` — prompt templates and presets
- `lib/` — utilities and supabase client
- `services/` — integrations (Gemini, snacks)
